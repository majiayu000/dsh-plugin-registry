发布前准备

自动发现要求根目录 package.json 声明 dsh.bundle。

{
  "dsh": {
    "bundle": {
      "patch": "./cordis.patch.yml"
    }
  }
}

提交后会发生什么

  1. GitHub 创建公开提交 Issue。
  2. 预检结果和维护者反馈集中记录。
  3. 按评论修复仓库后，在同一 Issue 跟进。
  4. 审核完成后进入目录同步。
