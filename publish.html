最低可安装契约

只有 dsh.client 不够，必须声明 dsh.bundle。

{
  "dsh": {
    "bundle": {
      "patch": "./cordis.patch.yml"
    }
  }
}

让自动发现生效

  1. 仓库包含真实、可运行的插件代码。
  2. 在 GitHub 仓库设置中添加 dsh-plugin Topic。
  3. 保持仓库公开且未归档；Fork 默认不会收录。
  4. 等待下一次定时同步，或在下面立即检查。
